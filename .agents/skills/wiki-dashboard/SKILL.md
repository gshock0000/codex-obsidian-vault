# Wiki dashboard

Dashboards are generated navigation and review views, not new evidence. Read existing indexes, logs, Wiki page states, and optionally live project records when the requested dashboard includes current work.

Separate sections that show compiled Wiki knowledge from sections that show live project status. Link every dashboard entry to its source page or record; do not restate unsupported facts.

Possible dashboard sections include recently confirmed knowledge commits, resources requiring review, active areas, Wiki graph gaps, recently updated projects, and open review proposals. If a dashboard file will be written, show its proposed location and content to the user first; write only after confirmation.
