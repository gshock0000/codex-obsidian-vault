# Wiki query

Start with `06_wiki/index.md` and the relevant resource, concept, entity, claim, or synthesis pages. Cite internal pages with wikilinks and state evidence limits when sources are stale or under review.

For questions about a project, first enumerate and search all Markdown files under the relevant `02_Project/<project>/` folder. Then read the files relevant to the question before reasoning or answering; do not rely solely on `overview.md` or the latest weekly report. For current progress or status, reconcile `overview.md` with relevant activities, plans, decisions, and the latest weekly report. Label the answer as live project context rather than Wiki knowledge. Do not promote queried material merely because it was useful in an answer.

When the answer would be a reusable comparison, explanation, or decision brief, offer a `wiki-synthesis` proposal rather than writing it automatically.
