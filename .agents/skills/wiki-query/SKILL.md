# Wiki query

Start with `06_wiki/index.md` and the relevant resource, concept, entity, claim, or synthesis pages. Cite internal pages with wikilinks and state evidence limits when sources are stale or under review.

For questions about current project progress, plans, open issues, or status, read the relevant `02_Project` records as the source of truth and label the answer as live project context rather than Wiki knowledge. Do not promote queried material merely because it was useful in an answer.

When the answer would be a reusable comparison, explanation, or decision brief, offer a `wiki-synthesis` proposal rather than writing it automatically.
